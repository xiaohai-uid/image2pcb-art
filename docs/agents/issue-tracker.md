# Local MaTt Issue Tracker

The project is not yet connected to GitHub or another issue tracker. Until that setup is explicitly approved, the vertical-slice tickets are stored in `.scratch/image2pcb-art/issues/` and the durable product decisions are stored in `docs/specs/`, `docs/adr/`, and `CONTEXT.md`.

This is a deliberate local fallback, not a claim that the MaTt tracker setup has completed.
